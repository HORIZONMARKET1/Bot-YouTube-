# Taj YouTube — Telegram-бот (хостинг bothost.ru)

Принимает ссылку на YouTube, Instagram или TikTok и присылает видео (360p–1080p), MP3 или фото.
Языки: таджикский и русский.

## Файлы

`bot.py`, `Dockerfile`, `requirements.txt`, `.gitignore`

## Деплой на bothost.ru

1. Залей проект в GitHub (приватный репозиторий) или загрузи архивом .zip через панель.
2. Создай бота: **Telegram → Python**, укажи репозиторий/архив.
3. В «Дополнительных настройках»:
   - включи **«Использовать собственный Dockerfile»** (нужен для ffmpeg и Deno);
   - **Главный файл**: `bot.py`.
4. Токен `BOT_TOKEN` bothost подставляет сам — вручную не нужен.
5. Добавь переменные (раздел «Переменные окружения», тариф Basic и выше):

| Переменная | Нужна | Описание |
|---|---|---|
| `ADMIN_ID` | да | твой Telegram ID (узнать: команда `/id`), можно несколько через запятую |
| `COOKIES_B64` | для YouTube/Instagram | cookies в Base64 |
| `PROXY_URL` | нет | прокси `http://логин:пароль@хост:порт` |
| `PROXY_FOR` | нет | `instagram` (по умолчанию) или `all` |
| `MAX_PARALLEL` | нет | загрузок одновременно (по умолчанию 2) |
| `RATE_LIMIT` | нет | загрузок в минуту на человека (по умолчанию 3) |
| `AUTO_UPDATE_YTDLP` | нет | `0` — не обновлять yt-dlp при запуске |

6. Сделай бота **администратором** каналов, на которые нужна подписка.

### Если нет раздела переменных (тариф Starter)

Положи в постоянную папку `/app/data` два необязательных файла:

- `/app/data/.env` с содержимым:
  ```
  ADMIN_ID=123456789
  ```
- `/app/data/cookies.txt` — cookies в формате Netscape.

Бот читает их при запуске. В Git эти файлы не кладём.

## Данные

База пользователей лежит в `/app/data/bot.db` — это постоянный том, он переживает деплои.
Всё вне `/app/data` при новом деплое стирается.

## Cookies (Instagram и YouTube)

1. Экспортируй cookies в формате Netscape (расширение «Get cookies.txt LOCALLY»).
   Для YouTube: окно инкогнито → вход → `youtube.com/robots.txt` → Export.
2. Объедини cookies в один файл (сверху строка `# Netscape HTTP Cookie File`).
3. Либо `base64 -w0 cookies.txt` → в `COOKIES_B64`, либо файл в `/app/data/cookies.txt`.

Используй отдельные аккаунты, не основные.

## Сторис Instagram

Ссылка на сторис (`instagram.com/stories/логин/…`), ссылка на хайлайт или команда `/stories логин` —
бот присылает фото и видео из сторис. Нужны cookies Instagram (`COOKIES_B64`); закрытые аккаунты
работают, только если аккаунт бота на них подписан.

## Распознавание музыки

Аудио, голосовое, видео или кружок (до 20 МБ) — бот определяет название и исполнителя (shazamio),
показывает обложку и кнопку «Скачать MP3» (поиск на YouTube). Работает неофициально, может перестать.

## Команды

Пользователь: `/start`, `/lang`, `/stories`, `/auto`, `/invite`.
Админ: `/stats`, `/broadcast`, `/channels`, `/update`, `/id`.

## Если перестало качать

- `/update` — обновит yt-dlp и перезапустит бота.
- Обнови cookies.
- Для Instagram с серверных IP может понадобиться прокси (`PROXY_URL`).

## Ограничения

- Лимит Telegram Bot API — 50 МБ (длинные видео сжимаются).
- Сжатие видео нагружает процессор: на Starter (256 МБ ОЗУ) лучше `MAX_PARALLEL=1`.
- Качай только то, на что есть права.
